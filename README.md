# AI Model Capability Leaderboard

A static leaderboard that ranks AI models across eight capability dimensions.

**Live site:** https://solis925.github.io/ai-model-leaderboard/

## What this repository contains

Only the published output:

- `index.html` — the complete single-file site (no build step, no dependencies)
- `robots.txt`

No source code, no raw data, no configuration. The site is a finished static artifact.

## Features

- 26 models scored across 8 capability dimensions
- Adjustable dimension weights with instant re-ranking
- Default and equal-weight presets
- Vertical bar overview chart
- Expandable per-model radar breakdown
- Multi-model comparison with overlaid radar and head-to-head table
- Vendor grouping statistics
- Light and dark theme
- Three languages: Traditional Chinese (default), Simplified Chinese, English
- Fully responsive, keyboard accessible
